## 关键接口与参数

### GET `/api/ppts`

| 参数 | 说明 | 校验 |
|------|------|------|
| search | 关键字，匹配 title/author/tags | ilike |
| category | slug | `PPT_CATEGORY_VALUES` (12 类) |
| status | draft/published/archived | 枚举 |
| sortBy | created_at/downloads/title | 默认 created_at |
| sortOrder | asc/desc | |
| page | 页码 | 默认 1 |
| pageSize | 每页数量 | 上限 50 |

### Server Action `getPPTs`

**DTO 映射现状** (⚠️ 待修复):

| 字段 | 当前映射 | DB 字段 | 问题 |
|------|----------|---------|------|
| tags | `row.tags ?? []` | tags | ✅ 正确 |
| language | `row.language ?? ''` | language | ✅ 正确 |
| description | `row.title` | **description** | ❌ 未使用 DB 字段 |
| file_size | `'未知'` | **file_size (integer)** | ❌ 未使用 DB 字段 |
| preview_url | `thumbnailUrl \|\| coverImageUrl` | - | ✅ 正确 |

**应修复为**:

```typescript
const toPPTDto = (row): PPT => ({
  // ...
  description: row.description ?? row.title ?? '',  // ✅ 使用 DB 字段
  file_size: row.fileSize ?? 0,                     // ✅ 使用 DB 字段 (integer)
  // ...
});
```
