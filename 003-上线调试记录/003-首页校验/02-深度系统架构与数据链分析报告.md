### 🔴 阻断点 4: DTO 映射未使用已有 DB 字段 (新发现)

| 字段 | DB 状态 | DTO 当前映射 | 应该映射 |
|------|---------|-------------|----------|
| description | ✅ 已有 (text) | `row.title` | `row.description ?? row.title` |
| file_size | ✅ 已有 (integer) | `'未知'` | `row.fileSize ?? 0` |
| file_format | ✅ 已有 (text) | 未映射 | `row.fileFormat ?? 'pptx'` |
| deleted_at | ✅ 已有 (timestamp) | 未过滤 | 查询时 `WHERE deleted_at IS NULL` |

## 3. 综合解决方案

### 阶段一：DTO 映射修复 (立即执行) 🔴

**文件**: `src/actions/ppt/ppt.ts`

```typescript
const toPPTDto = (row: typeof pptTable.$inferSelect): PPT => ({
  id: row.id,
  title: row.title,
  category: (row.category ?? 'general') as PPT['category'],
  author: row.author ?? 'Unknown',
  description: row.description ?? row.title ?? '',  // ✅ 使用 DB 字段
  tags: row.tags ?? [],
  language: row.language ?? '',
  slides_count: row.slidesCount ?? 0,
  file_size: row.fileSize ?? 0,                     // ✅ 使用 DB 字段 (integer)
  file_url: row.fileUrl,
  preview_url: row.thumbnailUrl ?? row.coverImageUrl ?? undefined,
  downloads: row.downloadCount ?? 0,
  views: row.viewCount ?? 0,
  status: (row.status ?? 'draft') as PPT['status'],
  uploaded_at: row.createdAt?.toISOString() ?? '',
  created_at: row.createdAt?.toISOString() ?? '',
  updated_at: row.updatedAt?.toISOString() ?? '',
});
```
