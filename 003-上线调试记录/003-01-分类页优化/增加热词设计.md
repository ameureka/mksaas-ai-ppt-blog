## 核心问题

定时任务 `updateHotKeywords()` 会 `DELETE` 全表再 `INSERT`，如果在现有表加 `is_pinned` 字段，置顶词会被删掉。

## 方案对比

| 方案 | 优点 | 缺点 |
|------|------|------|
| A: 现有表加 `is_pinned` 字段 | 不用新建表 | 要改定时任务逻辑，避免删置顶词 |
| B: 新建 `pinned_keywords` 表 | 逻辑隔离清晰，定时任务不用改 | 多一张表 |

**推荐方案 B**，更简单，不动现有逻辑。

## 方案 B 详细设计

### 1. 数据库

```sql
-- pinned_keywords 表
CREATE TABLE pinned_keywords (
  id TEXT PRIMARY KEY,
  keyword TEXT NOT NULL,
  rank INTEGER NOT NULL,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE UNIQUE INDEX pinned_keywords_rank_idx ON pinned_keywords(rank);
CREATE UNIQUE INDEX pinned_keywords_keyword_idx ON pinned_keywords(keyword);

-- 建议: id 使用 pkw_<uuid> 前缀；如需多语言/多租户可预留 locale/tenant_id 列
```

### 2. 读取优先级

```
┌─────────────────────────────────────────────────────────┐
│  读取优先级                                              │
│                                                         │
│  1. 运营置顶词 (pinned_keywords 表)  ← 新增             │
│  2. 自动计算词 (hot_keywords 表)     ← 现有             │
│  3. 默认兜底词                       ← 现有             │
└─────────────────────────────────────────────────────────┘
```

### 3. 读取逻辑改动

文件: `src/actions/hot-keywords.ts`

```typescript
export async function getHotKeywords(): Promise<string[]> {
  try {
    const db = await getDb();
    
    // 1. 读置顶词
    const pinned = await db
      .select({ keyword: pinnedKeywords.keyword })
      .from(pinnedKeywords)
      .orderBy(asc(pinnedKeywords.rank))
      .limit(8); // 置顶词上限，避免完全挤掉自动词
    
    // 2. 读自动词
    const auto = await db
      .select({ keyword: hotKeywords.keyword })
      .from(hotKeywords)
      .orderBy(asc(hotKeywords.rank))
      .limit(8);
    
    // 3. 合并去重取前8
    const seen = new Set<string>();
    const result: string[] = [];
    
    for (const row of [...pinned, ...auto]) {
      if (!seen.has(row.keyword) && result.length < 8) {
        seen.add(row.keyword);
        result.push(row.keyword);
      }
    }
    
    return result.length > 0 ? result : DEFAULT_HOT_KEYWORDS;
  } catch (error) {
    return DEFAULT_HOT_KEYWORDS;
  }
}
```

### 4. Admin API

```
POST   /api/admin/pinned-keywords     添加置顶词
DELETE /api/admin/pinned-keywords/:id 删除置顶词
PUT    /api/admin/pinned-keywords/:id 修改排序
GET    /api/admin/pinned-keywords     获取列表

约束与校验：
- 需要 admin 鉴权
- `keyword` 去空格/长度校验，唯一，不允许重复置顶
- `rank` 为正整数；拖拽重排需批量更新以满足唯一约束
- 置顶数量建议上限 8（与读取逻辑一致）
```

## 降级机制

1. **正常情况**：置顶词 + 自动词合并
2. **没有置顶词**：只显示自动词
3. **都没有**：显示默认兜底词
4. **网络失败**：前端显示默认词

**用户永远能看到热词，不会白屏。**
