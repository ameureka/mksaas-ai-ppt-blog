## 一、设计决策总览

| # | 模块 | 决策 |
|---|------|------|
| 1 | **向量方案** | pgvector (同库同表) |
| 2 | **Embedding 提供商** | 硅基流动 (SiliconFlow) |
| 3 | **Embedding 模型** | BAAI/bge-large-zh-v1.5 (1024维) |
| 4 | **索引类型** | HNSW |
| 5 | **搜索策略** | 向量 + SQL 混合 (降级方案) |
| 6 | **向量生成内容** | title + description + tags |
| 7 | **热门关键词** | 动态统计 (搜索60% + 下载40%) |
| 8 | **更新频率** | 每小时缓存 |
| 9 | **防抖时间** | 300ms |
| 10 | **搜索历史** | 未登录localStorage(10条) / 已登录数据库(50条) |
| 11 | **自动补全** | 历史 + 热词 + 标题，Top 8 |
| 12 | **空结果处理** | 纠错建议(Top 3) + 热门推荐(15个) |
| 13 | **搜索范围** | title + description + author + tags |
| 14 | **多语言** | 向量天然支持 + SQL繁简转换 |
| 15 | **全文索引** | 暂不实现，数据量>50,000时再加 |

## 三、数据库变更

### 3.1 ppt 表新增字段

```sql
-- 向量字段
ALTER TABLE ppt ADD COLUMN embedding vector(1024);
CREATE INDEX ppt_embedding_idx ON ppt USING hnsw (embedding vector_cosine_ops);
```

### 3.2 新增 search_log 表

```sql
CREATE TABLE search_log (
  id TEXT PRIMARY KEY,
  user_id TEXT REFERENCES "user"(id) ON DELETE SET NULL,
  keyword TEXT NOT NULL,
  result_count INTEGER DEFAULT 0,
  clicked_ppt_id TEXT,
  source TEXT DEFAULT 'search',
  from_suggestion BOOLEAN DEFAULT FALSE,
  search_type TEXT,          -- 'vector' | 'sql' | 'hybrid'
  duration_ms INTEGER,
  ip_address TEXT,
  user_agent TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### 3.3 新增 hot_keywords 表

```sql
CREATE TABLE hot_keywords (
  id TEXT PRIMARY KEY,
  keyword TEXT NOT NULL,
  search_count INTEGER DEFAULT 0,
  download_score NUMERIC DEFAULT 0,
  final_score NUMERIC DEFAULT 0,
  rank INTEGER NOT NULL,
  embedding vector(1024),    -- 用于纠错建议
  updated_at TIMESTAMP DEFAULT NOW()
);
```

## 八、关键决策理由

| 决策 | 理由 |
|------|------|
| **pgvector 而非 Pinecone** | Neon 原生支持，免费，同库同表，简单 |
| **硅基流动 而非 OpenAI** | 中文效果最好，便宜，国内服务器 |
| **HNSW 而非 IVFFlat** | 读多写少场景，查询更快 |
| **混合搜索** | 向量优先，SQL 兜底，保证可用性 |
| **每小时缓存热词** | 平衡性能和时效 |
| **暂不加全文索引** | 10,000 条数据 ILIKE 够用 |
