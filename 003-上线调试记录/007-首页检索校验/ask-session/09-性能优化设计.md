## 一、当前阶段性能保障

### 1.1 已有索引

```sql
-- 向量索引 (HNSW)
CREATE INDEX ppt_embedding_idx ON ppt USING hnsw (embedding vector_cosine_ops);

-- 业务索引
CREATE INDEX ppt_category_idx ON ppt(category);
CREATE INDEX ppt_status_idx ON ppt(status);
CREATE INDEX ppt_download_count_idx ON ppt(download_count);
CREATE INDEX ppt_created_at_idx ON ppt(created_at);
```

|----------|----------|
| 向量搜索 (HNSW) | < 50ms |
| SQL ILIKE | < 100ms |
| 混合搜索 | < 150ms |

## 二、未来优化方案 (预留)

### 2.1 触发条件

当满足以下条件时考虑添加全文索引：
- 数据量 > 50,000 条
- SQL 降级搜索耗时 > 500ms
- 用户反馈搜索慢

### 2.2 PostgreSQL 全文索引方案

```sql
-- 添加 tsvector 列
ALTER TABLE ppt ADD COLUMN search_vector tsvector;

-- 生成搜索向量 (中文需要 zhparser 扩展)
UPDATE ppt SET search_vector = 
  to_tsvector('simple', coalesce(title, '') || ' ' || coalesce(description, ''));

-- 创建 GIN 索引
CREATE INDEX ppt_search_vector_idx ON ppt USING gin(search_vector);

-- 全文搜索查询
SELECT * FROM ppt 
WHERE search_vector @@ plainto_tsquery('simple', '年终总结');
```

### 2.3 中文全文搜索

Neon PostgreSQL 中文支持选项：
- `pg_jieba` - 结巴分词
- `zhparser` - 中文分词
- 或继续使用向量搜索 (推荐)
