## 二、更新频率

### 2.1 方案对比

| 方案 | 优势 | 劣势 | 适合场景 |
|------|------|------|----------|
| 实时计算 | 最新最准 | 每次请求都查库，性能差 | 高并发不适合 |
| **每小时缓存** ✅ | 平衡性能和时效 | 最多延迟1小时 | **推荐** |
| 每天更新 | 性能最好 | 时效性差，新热点反应慢 | 数据变化慢的场景 |

### 2.2 缓存流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     每小时缓存方案                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  定时任务 (每小时整点)                                                        │
│  └── 统计最近7天搜索日志                                                      │
│      └── 统计下载量 Top PPT 关键词                                            │
│          └── 合并计算 Top 8 热词                                              │
│              └── 写入 hot_keywords 缓存表                                     │
│                                                                             │
│  用户请求首页                                                                 │
│  └── 直接读取 hot_keywords 表 (< 1ms)                                        │
│      └── 返回 8 个热门关键词                                                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 三、数据库表设计

### 3.1 搜索日志表 (search_log)

```sql
CREATE TABLE search_log (
  id TEXT PRIMARY KEY,
  
  -- 用户关联 (可选，支持匿名搜索)
  user_id TEXT REFERENCES "user"(id) ON DELETE SET NULL,
  
  -- 搜索内容
  keyword TEXT NOT NULL,
  
  -- 搜索上下文
  result_count INTEGER DEFAULT 0,
  clicked_ppt_id TEXT,
  
  -- 来源信息
  source TEXT DEFAULT 'search',  -- search, hot_keyword, suggestion
  
  -- 设备信息
  ip_address TEXT,
  user_agent TEXT,
  
  -- 时间
  created_at TIMESTAMP DEFAULT NOW()
);

-- 索引
CREATE INDEX search_log_keyword_idx ON search_log(keyword);
CREATE INDEX search_log_user_id_idx ON search_log(user_id);
CREATE INDEX search_log_created_at_idx ON search_log(created_at);
```

### 3.2 热词缓存表 (hot_keywords)

```sql
CREATE TABLE hot_keywords (
  id TEXT PRIMARY KEY,
  keyword TEXT NOT NULL,
  
  -- 统计数据
  search_count INTEGER DEFAULT 0,
  download_score NUMERIC DEFAULT 0,
  final_score NUMERIC DEFAULT 0,
  
  -- 排序
  rank INTEGER NOT NULL,
  
  -- 更新时间
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE UNIQUE INDEX hot_keywords_rank_idx ON hot_keywords(rank);
```

**Drizzle Schema**:


## 四、热词计算逻辑

### 4.1 定时任务

```typescript
// scripts/update-hot-keywords.ts 或 cron job
async function updateHotKeywords() {
  const db = await getDb();
  
  // 1. 统计最近7天搜索词频率
  const searchStats = await db.execute(sql`
    SELECT keyword, COUNT(*) as count
    FROM search_log
    WHERE created_at > NOW() - INTERVAL '7 days'
    GROUP BY keyword
    ORDER BY count DESC
    LIMIT 50
  `);
  
  // 2. 统计下载量 Top PPT 的关键词 (从 tags 提取)
  const downloadStats = await db.execute(sql`
    SELECT unnest(tags) as keyword, SUM(download_count) as score
    FROM ppt
    WHERE deleted_at IS NULL AND tags IS NOT NULL
    GROUP BY keyword
    ORDER BY score DESC
    LIMIT 50
  `);
  
  // 3. 合并计算 (搜索 60% + 下载 40%)
  const merged = mergeAndScore(searchStats.rows, downloadStats.rows, {
    searchWeight: 0.6,
    downloadWeight: 0.4,
  });
  
  // 4. 取 Top 8 写入缓存表
  const top8 = merged.slice(0, 8);
  
  await db.delete(hotKeywords);
  await db.insert(hotKeywords).values(
    top8.map((item, index) => ({
      id: `hot_${index + 1}`,
      keyword: item.keyword,
      searchCount: item.searchCount || 0,
      downloadScore: String(item.downloadScore || 0),
      finalScore: String(item.finalScore),
      rank: index + 1,
      updatedAt: new Date(),
    }))
  );
  
  console.log(`[HotKeywords] Updated ${top8.length} keywords`);
}

// 合并计算函数
function mergeAndScore(
  searchStats: { keyword: string; count: number }[],
  downloadStats: { keyword: string; score: number }[],
  weights: { searchWeight: number; downloadWeight: number }
) {
  const map = new Map<string, { searchCount: number; downloadScore: number }>();
  
  // 归一化搜索数据
  const maxSearch = Math.max(...searchStats.map(s => s.count), 1);
  for (const s of searchStats) {
    map.set(s.keyword, {
      searchCount: s.count,
      downloadScore: 0,
    });
  }
  
  // 归一化下载数据
  const maxDownload = Math.max(...downloadStats.map(d => d.score), 1);
  for (const d of downloadStats) {
    const existing = map.get(d.keyword) || { searchCount: 0, downloadScore: 0 };
    existing.downloadScore = d.score;
    map.set(d.keyword, existing);
  }
  
  // 计算最终得分
  const results = Array.from(map.entries()).map(([keyword, data]) => ({
    keyword,
    searchCount: data.searchCount,
    downloadScore: data.downloadScore,
    finalScore: 
      (data.searchCount / maxSearch) * weights.searchWeight +
      (data.downloadScore / maxDownload) * weights.downloadWeight,
  }));
  
  // 按最终得分排序
  return results.sort((a, b) => b.finalScore - a.finalScore);
}
```

### 4.2 API 读取

```typescript
// src/actions/hot-keywords.ts
export async function getHotKeywords(): Promise<string[]> {
  const db = await getDb();
  
  const rows = await db
    .select({ keyword: hotKeywords.keyword })
    .from(hotKeywords)
    .orderBy(asc(hotKeywords.rank))
    .limit(8);
  
  return rows.map(r => r.keyword);
}
```

## 五、统计能力

有了 `search_log` 表，后续可以统计：

| 统计项 | 用途 | SQL 示例 |
|--------|------|----------|

| 搜索趋势 | 运营分析 | 按天/周/月聚合 |
