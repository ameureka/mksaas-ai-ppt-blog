# PPT 卡片分析设计（依据《应用模块数据库分析方法论》）

**生成时间**: 2025-12-11  
**分析范围**: 首页/分类页/搜索结果中的 PPT 卡片展示

---

## 一、配置与常量定义（Step 1）

| 位置 | 内容 |
|------|------|
| `src/lib/constants/ppt.ts` | 分类 slug 枚举 `PPT_CATEGORIES` |
| `src/lib/constants/ppt-category-meta.ts` | 分类元数据（中文名、图标、预览图） |
| 组件内部 | 语言默认"中文"，无枚举校验 |

---

## 二、数据库字段（Step 2）

**表**: `ppt`（`src/db/schema.ts`）

| 字段 | 类型 | 卡片用途 |
|------|------|----------|
| `id` | text PK | 详情页链接 `/ppt/{id}` |
| `title` | text NOT NULL | 标题（两行截断） |
| `category` | text | 分类 Badge |
| `tags` | text[] | 标签 Badge 列表 |
| `language` | text | 右上角语言标识 |
| `thumbnail_url` / `cover_image_url` | text | 封面图 |
| `slides_count` | integer | 页数显示 |
| `download_count` | integer | 下载数统计 |
| `view_count` | integer | 浏览数统计 |
| `status` | text | 过滤条件（需 `published`） |
| `deleted_at` | timestamp | 软删除过滤（需 NULL） |

**索引**: `ppt_category_idx`, `ppt_status_idx`, `ppt_status_created_idx`

---

## 三、数据链路（Step 3-5）

```
用户访问首页/分类页
       ↓
fetch('/api/ppts?...') 或 hybridSearch()
       ↓
getPPTs() → Drizzle 查询 (status='published' AND deleted_at IS NULL)
       ↓
mapHomeItems() / mapCategoryItems() 字段标准化
       ↓
<PPTCard ppt={...} onDownload={...} />
```

### 字段映射（home-map.ts / map-items.ts）

| API 返回字段 | 卡片字段 | 默认值 |
|-------------|---------|--------|
| `preview_url` / `thumbnailUrl` / `cover_image_url` | `previewUrl` | `/placeholder.svg` |
| `downloads` / `downloadCount` | `downloads` | `0` |
| `views` / `viewCount` | `views` | `0` |
| `slides_count` / `slidesCount` | `pages` | `0` |
| `language` | `language` | `'中文'` |
| `category` | `category` | `'其他'` |
| `tags` | `tags` | `[]` |

## 五、SQL 过滤要点（Step 6）

```sql
SELECT * FROM ppt
WHERE status = 'published'
  AND deleted_at IS NULL
  [AND category = ?]
ORDER BY download_count DESC / created_at DESC
LIMIT 8/12/20
```

## 六、优缺点分析（Step 8）

### ✅ 优点
- 字段回退完善，图片/语言/计数均有默认值
- 统计数据直观（下载/浏览/页数）
- CTA 按钮清晰

### ⚠️ 潜在问题
1. 分类 Badge 直接显示 slug，缺少中文映射
2. 下载/浏览数 <1000 时显示 `0.xk` 不友好
3. 语言字段无枚举校验

### 📋 改进建议
- 分类显示：使用 `categoryMeta[slug].name` 映射中文
- 数值格式：<1000 显示整数，≥1000 显示 `x.xk`
- 数据校验：导入时确保 `thumbnail_url`、`slides_count` 有值
