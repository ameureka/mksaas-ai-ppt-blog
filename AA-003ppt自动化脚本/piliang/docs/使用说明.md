## 环境准备

### 1. 安装 Python 依赖

```bash
cd AA-003ppt自动化脚本/piliang
pip install -e ".[dev]"
```

### 2. 安装系统依赖

```bash
# macOS
brew install --cask libreoffice  # PPTX 转换和封面生成
brew install poppler             # PDF 转图片 (pdftoppm)
brew install unar                # RAR 解压（可选）
```

### 3. 配置环境变量

```bash
cp .env.example .env
```

编辑 `.env` 文件，配置以下关键项：

```bash
# 数据目录
PILIANG_DATA_ROOT=data

# AI 配置（二选一）
# 方式1: DeepSeek (推荐，快速 2-3s)
AI_PROVIDER=deepseek
SILICONFLOW_API_KEY=sk-xxx  # 从 https://cloud.siliconflow.cn/ 获取

# 方式2: Gemini CLI (免费，启动约 15s)
# AI_PROVIDER=gemini

# 存储配置（Cloudflare R2 示例）
STORAGE_ENDPOINT="https://xxx.r2.cloudflarestorage.com"
STORAGE_BUCKET_NAME="ppt-assets"
STORAGE_ACCESS_KEY_ID="your_access_key"
STORAGE_SECRET_ACCESS_KEY="your_secret_key"
STORAGE_REGION="auto"
STORAGE_PUBLIC_URL="https://your-cdn.com"
STORAGE_DRY_RUN=true  # 设为 false 启用真实上传
```

### 4. 验证安装

```bash
pytest tests
# 预期: 70 passed
```

## 快速开始

### 最简单的测试运行

```bash
# 使用示例清单运行（不启用 AI）
python scripts/run_smoke_batch.py \
  --manifest fixtures/mini_batch_manifest.json \
  --db /tmp/test.db
```

### 启用 AI 的完整运行

```bash
# 设置 AI 密钥
export SILICONFLOW_API_KEY=sk-xxx
export AI_PROVIDER=deepseek

# 运行完整流程
python scripts/run_smoke_batch.py \
  --manifest fixtures/ppt_hangye_manifest.json \
  --db data/assets.db \
  --enable-ai
```

### 真实上传到 R2/S3

```bash
# 设置所有环境变量
export SILICONFLOW_API_KEY=sk-xxx
export AI_PROVIDER=deepseek
export STORAGE_DRY_RUN=false
export STORAGE_ENDPOINT="https://xxx.r2.cloudflarestorage.com"
export STORAGE_BUCKET_NAME="ppt-assets"
export STORAGE_ACCESS_KEY_ID="your_key"
export STORAGE_SECRET_ACCESS_KEY="your_secret"
export STORAGE_PUBLIC_URL="https://your-cdn.com"

# 运行完整流程（含真实上传）
python scripts/run_smoke_batch.py \
  --manifest fixtures/ppt_hangye_manifest.json \
  --db data/assets.db \
  --enable-ai \
  --ai-command "python scripts/ai_caller.py {prompt} {output}"

# 验证上传结果
curl -I https://your-cdn.com/thumbs/ppt_hangye/ppt_1203.webp
```

## 完整流程操作

### 步骤 1: 准备输入数据

#### 方式 A: 从爬虫数据导入

```bash
# 确保 crawler.db 和 downloads/ 目录已就绪
python scripts/ingest_crawler.py --manifest fixtures/your_manifest.json
```

#### 方式 B: 手动准备标准输入包

创建目录结构：

```
data/input_raw/{channel_id}/{aid}/
├── main.pptx    # 必需：主 PPTX 文件
├── meta.json    # 必需：元数据
└── cover.jpg    # 可选：封面图
```

`meta.json` 示例：

```json
{
  "aid": "139646",
  "title": "商务汇报PPT模板",
  "channel_id": "ppt_moban",
  "channel_name": "PPT模板网",
  "original_tags": ["商务", "汇报", "简约"]
}
```

### 步骤 2: 创建 Manifest 清单

在 `fixtures/` 目录创建清单文件：

```json
{
  "batch_id": "my-batch-001",
  "notes": "我的批处理任务",
  "aids": [
    {
      "aid": "139646",
      "channel_id": "ppt_moban",
      "input_dir": "input_raw/ppt_moban/139646"
    }
  ]
}
```

### 步骤 3: 运行流水线

#### 基础运行（不含 AI）

```bash
python scripts/run_smoke_batch.py \
  --manifest fixtures/my_manifest.json \
  --db data/my_batch.db
```

#### 完整运行（含 AI 内容丰富）

```bash
# 设置环境变量
export SILICONFLOW_API_KEY=sk-xxx
export AI_PROVIDER=deepseek

# 运行
python scripts/run_smoke_batch.py \
  --manifest fixtures/my_manifest.json \
  --db data/my_batch.db \
  --enable-ai
```

#### 指定阶段范围

```bash
# 只运行 A 到 D 阶段
python scripts/run_smoke_batch.py \
  --manifest fixtures/my_manifest.json \
  --db data/my_batch.db \
  --from-stage A \
  --to-stage D
```

### 步骤 4: 查看输出

```bash
# 查看导出文件
ls -la data/output/export/

# 输出文件：
# - ppthub-init-{batch_id}.json   # PPTHub 导入数据
# - ppthub-init-{batch_id}.csv    # Excel 可读格式
# - ppthub-export-report-{batch_id}.json  # 处理报告
```

## AI 配置

### DeepSeek (推荐)

通过 SiliconFlow API 调用 DeepSeek-V3，速度快（2-3s/请求）。

```bash
# .env 配置
AI_PROVIDER=deepseek
SILICONFLOW_API_KEY=sk-xxx

# 或运行时设置
export AI_PROVIDER=deepseek
export SILICONFLOW_API_KEY=sk-xxx
```

获取 API Key: https://cloud.siliconflow.cn/

### Gemini CLI

使用本地 Gemini CLI，免费但启动较慢（约 15s）。

```bash
# 先登录 Gemini CLI
gemini

# .env 配置
AI_PROVIDER=gemini
```

### AI 输出字段

AI 会生成以下字段用于 SEO 和向量化：

| 字段 | 说明 | 长度 |
|------|------|------|
| `ai_summary` | 卡片摘要 | ≤100 字 |
| `ai_content_summary` | 详细内容总结 | 300-800 字 |
| `ai_keywords` | 关键词数组 | 5-10 个 |
| `ai_scenario` | 适用场景 | - |
| `ai_color_scheme` | 配色方案 | - |
| `ai_structure_features` | 结构特点 | - |
| `ai_template_features` | 模板特色 | - |
| `ppthub_category` | 分类 slug | 12 选 1 |

## 输出说明

### 目录结构

```
data/output/
├── etl/{channel}/          # Workshop A: 标准化 PPTX
│   └── {aid}.pptx
├── clean/{channel}/        # Workshop B: 清洗后 PPTX
│   └── {aid}-clean.pptx
├── cover/{channel}/        # Workshop Cover: 封面图
│   ├── {aid}-cover.webp    # 640×360
│   └── {aid}-preview.webp  # 1920×1080
├── final/{channel}/        # Workshop D: 最终成品
│   ├── {aid}-final.pptx
│   ├── {aid}-cover.webp
│   └── {aid}-preview.webp
└── export/                 # Workshop F: 导出文件
    ├── ppthub-init-{batch_id}.json
    ├── ppthub-init-{batch_id}.csv
    └── ppthub-export-report-{batch_id}.json
```

### JSON 导出格式

```json
{
  "meta": {
    "schema_version": "ppt-import-v2",
    "exported_at": "2024-12-15T12:00:00Z",
    "source": "piliang",
    "source_batch_id": "my-batch-001"
  },
  "items": [
    {
      "id": "ppt_1203",
      "title": "商务汇报PPT模板",
      "category": "business",
      "tags": ["商务", "汇报"],
      "description": "详细的内容描述...",
      "slides_count": 24,
      "file_url": "https://aippt.guochunlin.com/ppts/ppt_hangye/ppt_1203.pptx",
      "thumbnail_url": "https://aippt.guochunlin.com/thumbs/ppt_hangye/ppt_1203.webp",
      "ai_summary": "简短摘要",
      "ai_content_summary": "详细内容总结...",
      "ai_keywords": ["商务", "汇报", "简约"]
    }
  ]
}
```

> 注：当 `STORAGE_DRY_RUN=false` 时，`file_url` 和 `thumbnail_url` 为真实可访问的 CDN 地址。

## 故障排查

### LibreOffice 找不到

```bash
# 检查安装
ls /Applications/LibreOffice.app/Contents/MacOS/soffice

# 如果不存在，安装
brew install --cask libreoffice
```

### pdftoppm 找不到

```bash
# 安装 poppler
brew install poppler

# 验证
which pdftoppm
```

### AI 调用失败

```bash
# 检查 API Key
echo $SILICONFLOW_API_KEY

# 测试连接
curl -X POST https://api.siliconflow.cn/v1/chat/completions \
  -H "Authorization: Bearer $SILICONFLOW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-ai/DeepSeek-V3","messages":[{"role":"user","content":"hi"}]}'
```

### 封面生成失败

1. 确保 LibreOffice 已安装
2. 确保 pdftoppm 可用
3. 检查 PPTX 文件是否损坏
4. 流水线会自动回退到使用原始封面

### 分类匹配不准确

1. 检查 `configs/category-mapping.yaml` 关键词配置
2. 启用 AI 模式获得更准确的分类
3. 规则匹配优先，AI 作为内容丰富补充

### S3/R2 上传失败

```bash
# 检查环境变量
echo $STORAGE_ENDPOINT
echo $STORAGE_DRY_RUN  # 应为 false

# 验证凭证（使用 AWS CLI）
aws s3 ls s3://your-bucket --endpoint-url $STORAGE_ENDPOINT

# 常见问题：
# 1. STORAGE_DRY_RUN 仍为 true
# 2. 凭证错误或过期
# 3. Bucket 不存在或无写入权限
# 4. 网络连接问题
```

> 已验证：Cloudflare R2 上传正常工作，6/6 文件全部成功上传。

## 流水线阶段说明

| 阶段 | 名称 | 功能 | 状态 |
|------|------|------|------|
| 0 | Ingest | 从爬虫数据生成标准输入包 | ✅ |
| Preflight | 校验门 | 校验输入包完整性 | ✅ |
| A | ETL | 页数/大小/命名标准化 | ✅ |
| B | Clean | 敏感词替换、尾页裁剪、品牌注入 | ✅ |
| C | AI | 规则分类 + AI 内容丰富 | ✅ |
| Cover | 封面 | 从清洗后 PPTX 生成封面 | ✅ |
| D | Pack | 本地成品打包归档 | ✅ |
| E | Publish | 上传到 S3/R2 | ✅ |
| Final Gate | 校验门 | 导出阻断校验 | ✅ |
| F | Export | 导出 JSON/CSV/报告 | ✅ |

> 全部阶段已验证通过，包括真实上传到 Cloudflare R2。
