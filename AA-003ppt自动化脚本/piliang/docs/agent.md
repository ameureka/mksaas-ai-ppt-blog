## 1. 项目简介 (Overview)

本项目旨在建立一条高效、自动化的 PPT 资源**生产流水线 (Production Pipeline)**。它将从 `pachong` 项目下载的原始 PPT 模板进行深度清洗、品牌重塑 (Rebranding) 为 **PPTHub** (`https://www.ppthub.shop/`)，并通过异步 AI 流程提取结构化元数据，最终输出高质量、可检索的成品 PPT 资源。

本项目是 `pachong` (爬虫) 项目的下游，专注于**数据增值**和**标准化**。

## 2. 核心目标 (Key Objectives)

-   **去品牌化**: 彻底清除原始来源（如“第一PPT”）的所有品牌痕迹、广告和版权信息。
-   **品牌注入**: 统一注入 PPTHub 的品牌标识、网址和结束页。
-   **内容清洗**: 移除无效页面、占位符文本中的敏感词。
-   **AI 增强**: 结合 Gemini CLI 提取高级元数据（摘要、关键词、适用场景、结构特色等）。
-   **标准化输出**: 生成统一命名、结构清晰的 PPTX 文件、封面图和数据库记录。

## 3. 技术路线 (Tech Stack)

-   **核心语言**: Python 3.10+
-   **PPT 操作**: `python-pptx` (用于 PPTX 文件的读写、修改)
-   **AI 交互**: Gemini CLI (通过文件交换模式进行异步 AI 增强)
-   **数据持久化**: SQLite (用于记录处理状态和 AI 提取的元数据)

## 4. 核心处理流程 (Pipeline Stages) - "四大车间"

### 4.1 车间 A：预处理 (ETL & Normalization)
-   **任务**: 从原始下载的 `.zip` / `.rar` 包中提取 `.pptx` 主文件。
-   **输出**: 标准化命名的 `.pptx` 文件 (e.g., `{aid}-{title}.pptx`) 和对应的封面图 (`{aid}-cover.jpg`)。
-   **新增字段**: 读取 PPTX 文件的总页数 (`pages_count`)。

### 4.2 车间 B：深度清洗 (Deep Cleaning)
-   **任务**: 移除旧品牌痕迹，注入 PPTHub 品牌信息。
-   **关键操作**:
    -   **全局文本替换**: 查找并替换/删除 `"第一PPT"`, `"1ppt.com"` 等。
    -   **元数据重置**: 修改 PPT 的 `Core Properties` (作者、公司、备注) 为 PPTHub 品牌信息。
    -   **母版扫描**: 检查并清除 `slide_masters` 中的品牌痕迹。
    -   **页面手术**: 
        -   清洗首页标题/副标题。
        -   **强制删除倒数后 3 页**，并向前扫描，删除所有包含敏感词的页面。
    -   **品牌注入**: 在末尾追加 **1 页** 标准化的 PPTHub 品牌结束页 (`brand_end_slide.pptx`)。

### 4.3 车间 C：AI 内容理解 (AI Enrichment) - *异步文件交换模式*
-   **任务**: 提取高级元数据，为向量化检索做准备。
-   **流程**:
    1.  **Python 侧 (`ai_generator.py`)**: 从已清洗的 PPT 中提取文本，并结合数据库信息，生成 `{aid}.md` Prompt 文件至 `ai_tasks/pending/` 目录。
        *   Prompt 要求 Gemini 生成 `summary`, `keywords`, `scenario`, `color_scheme`, `structure_features`, `template_features`。
    2.  **Gemini CLI Agent 侧**: 批量处理 `pending/` 目录下的 Prompt 文件，将 AI 输出的 JSON 结果保存至 `ai_tasks/completed/`。
    3.  **Python 侧 (`ai_backfiller.py`)**: 读取 `completed/` 目录下的 AI 结果，更新至数据库。
-   **输出**: 数据库中新增 `ai_summary`, `ai_keywords` 等字段，并构建 `embedding_text`。

### 4.4 车间 D：成品输出 (Output)
-   **文件**: 处理后的 PPTX 文件和封面图将保存至 `output/{channel_id}/` 目录。
-   **数据**: 最终的元数据（包含 AI 增强信息）将存储在 SQLite 数据库中 (`assets.db`)。
