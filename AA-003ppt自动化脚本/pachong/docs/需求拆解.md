需求拆解

  - 目标：批量解析 https://www.1ppt.com 的模板资源，提取 PPT 元数据并自动化下载。
  - 约束：页面为 GB2312、带分页；下载页要求 Referer，且含本地/夸克双通道；需可由 MCP/大模型统一调度。

  任务规划

  - Task 1：站点结构映射——梳理入口列表、分页模式及详情 URL 组织；确定需要抓取的 DOM 区域与字段。
  - Task 2：详情页洞察——枚举需提取的元信息（频道、标签、文件大小、下载入口等），确认 JS 动态部分（kuakeajax）对下载链路的影响。
  - Task 3：下载页解析——验证本地 CDN 链接与夸克链接的真实位置、所需 Header，并确认防盗链/重定向策略。
  - Task 4：实现路径设计——分解为可落地的脚本/工具：列表抓取、详情解析、下载解析、实体下载；结合 Playwright+MCP 的交互流程。

  页面结构要点

  - 列表页：page_utf8.html:122-140 展示 ul.tplist > li，每个元素含封面 img、详情 a 和分类 span。分页遵循 ppt_moban_{page}.html 规则，可直接用 HTTP/Playwright 迭代。
  - 详情页：article_136292_utf8.html:71-135 给出标题、频道、更新时间、版本、尺寸等字段，并在 #xiazai 处放出 /plus/download.php?open=0&aid={aid}&cid=3 入口，同时异步调用 /plus/kuakeajax.php?... 填充夸克
    链接。
  - 下载页：需带 Referer: https://www.1ppt.com/article/{aid}.html 才能避免 302 回详情。成功后可见 download_136292_real_utf8.html:69-88 中两个按钮：
    • 本地直链：https://ppt.1ppt.com/uploads/soft/2508/3-250Q9145A6.zip
    • 夸克网盘：https://pan.quark.cn/s/74a6d979d5f3
    直链可直接下载 ZIP/RAR，夸克链接也可由 curl https://www.1ppt.com/plus/kuakeajax.php?...（示例 aid=136292）解析得到。
  - 防护：download.php 无 Referer 会 302（curl -I ... 结果），因此脚本需先获取详情或显式设置 Header。站点会下发 acw_tc Cookie，可原样携带但非强制。请求频率应限速以规避封禁。

  落地方案（Playwright + MCP）

  1. listTemplates(page) 工具
      - Playwright 进入 /moban/ppt_moban_{page}.html，等待 .tplist li，输出 [{title, detailUrl, cover, category}]。可追加 hasNext 或下一页 URL。
  2. fetchTemplateDetail(detailUrl) 工具
      - 访问详情页，解析 #jieshao 文案、info_left 中的频道/版本/大小/比例/附件类型、tag 列表以及 aid（可从 URL 或 data 属性提取）。返回结构体以供存档。
  3. resolveDownloadLinks(aid, detailUrl) 工具
      - 访问 download.php，附带 Referer，解析 .downloadlist li 获得本地直链与文本描述。
      - 并调用 /plus/kuakeajax.php?open=0&aid={aid}&cid=3 获取夸克链接；若站点改动，也可让 Playwright 直接读取 #kuakelink。
  4. downloadAsset(url, meta) 工具
      - 负责真正下载 ZIP/RAR。对本地 CDN 直接 HTTP GET；若走夸克，则可：
        a) 使用浏览器保持登录并点击；
        b) 调用夸克开放接口（若有凭据）；
        c) 至少把 share URL 存入任务队列供人工/其他脚本处理。
      - 下载成功后按 {channel}/{aid}-{slug}.zip 命名，写入数据库/清单，记录标签、来源页等元信息。
  5. 编排：让大模型通过 MCP 顺序调用上述工具，或用脚本串联（分页→详情→下载）。MCP 的优势是 LLM 可根据页面结构调整 CSS 选择器或处理异常（验证码、缺页等）。

  验证结论

  - 首页/分类页提供完整数据入口；详情页包含下载列表和 kuakeajax 钩子；下载页双通道直链已定位，真实文件位于 ppt.1ppt.com（需 Referer）和 pan.quark.cn。
  - 依赖最小：HTTP/Playwright、简单头部控制即可，无需复杂逆向。MCP 可将这套流程工具化，输出高效批量下载方案。
