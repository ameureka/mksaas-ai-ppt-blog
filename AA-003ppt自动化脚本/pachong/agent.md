## 1. 项目简介 (Overview)

**PPT Crawler** 是一个高性能、模块化且配置驱动的自动化爬虫系统，专门用于从 `1ppt.com` 批量抓取、解析并下载 PPT 模板资源。

该项目不仅仅是一个下载器，更是一个**结构化数据构建工具**。它能够：
- 自动遍历指定频道的全量分页。
- 智能解析详情页，提取标题、分类、标签等元数据。
- 解决反爬虫限制（Referer 校验），同时下载 **PPT 源文件** (`.zip/.rar`) 和 **封面图片**。
- 将所有任务状态和元数据持久化到 **SQLite 数据库**，支持断点续传和自动去重。
- 提供 **CLI** 和 **MCP (Model Context Protocol)** 两种交互接口。

## 5. 开发指南 (Development)

### 目录结构
- `src/config`: 配置文件与 Schema 校验。
- `src/core`: 爬虫核心逻辑 (Browser, Downloader, Service)。
- `src/database`: 数据库连接与 Repository。
- `src/mcp`: MCP Server 实现。

### 关键策略
- **去重**: 数据库基于 URL 进行 `UPSERT`，确保同一资源不会重复记录。
- **重试**: `Downloader` 内置 3 次指数退避重试机制。
- **反爬**: `DownloadResolver` 和 `Downloader` 均会自动注入 `Referer` 头。
