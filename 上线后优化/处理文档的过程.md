## Phase 5: 更新链接 (UPDATE LINKS)

### 批量替换命令

```bash
# 替换目录名引用
find . -name "*.md" -exec sed -i '' \
  -e 's|0-快速开始|00-getting-started|g' \
  -e 's|1-架构与设计|01-architecture|g' \
  -e 's|2-核心概念|02-concepts|g' \
  -e 's|3-开发指南|03-guides|g' \
  -e 's|4-功能模块|04-modules|g' \
  -e 's|6-参考文档和部署指南|05-reference|g' \
  {} \;

# 替换相对路径引用
find . -name "*.md" -exec sed -i '' \
  -e 's|\.\./diagrams/|../01-architecture/diagrams/|g' \
  -e 's|\.\./reports/|../07-reports/|g' \
  -e 's|\.\./QA/|../06-qa/|g' \
  -e 's|/vercel-dev/|/08-dev-notes/|g' \
  {} \;
```

## 经验总结

### 成功要素

1. **先分析后执行** - 充分理解现状再动手
2. **使用 TodoWrite** - 跟踪多步骤任务
3. **批量操作** - sed 批量替换提高效率
4. **验证每一步** - 确保文件数量一致

### 注意事项

1. **备份** - 重大操作前建议备份
2. **sed 兼容性** - macOS 和 Linux 的 sed 语法不同
3. **特殊字符** - 中文路径在 sed 中需要正确处理
4. **链接验证** - 迁移后务必验证所有内部链接
