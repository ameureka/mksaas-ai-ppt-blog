## 二、数据库 Schema (Step 2)

### 2.1 核心表结构

#### 表1: `user_download_history` (用户下载历史)

```sql
CREATE TABLE user_download_history (
  id              TEXT PRIMARY KEY,
  user_id         TEXT REFERENCES "user"(id) ON DELETE CASCADE,
  ppt_id          TEXT NOT NULL REFERENCES ppt(id) ON DELETE CASCADE,
  download_method TEXT NOT NULL,        -- 'firstFree' | 'credits' | 'ad'
  credits_spent   INTEGER DEFAULT 0,    -- 消耗积分数
  ip_address      TEXT,                 -- 匿名用户追踪
  downloaded_at   TIMESTAMP NOT NULL DEFAULT NOW()

-- 索引
CREATE INDEX download_user_ppt_idx ON user_download_history(user_id, ppt_id);
CREATE INDEX download_user_idx ON user_download_history(user_id);
CREATE INDEX download_ppt_idx ON user_download_history(ppt_id);
CREATE INDEX download_method_date_idx ON user_download_history(download_method, downloaded_at);

```sql
CREATE TABLE ad_watch_record (

### 4.2 核心下载 API 流程

```typescript
// POST /api/ppts/[id]/download
export async function POST(req, { params }) {
  const { id } = params;
  const { method, downloadToken } = await req.json();
  
  // 1. 检查登录开关
  if (websiteConfig.features.pptRequireLoginForDownload && !userId) {
    return { error: 'Login required' };
  }
  
  // 2. 获取 PPT 详情
  const ppt = await getPPTById(id);
  
  // 3. 按下载方式验证
  switch (method) {
    case 'firstFree':
      // 检查是否已下载过
      const existing = await db.select().from(userDownloadHistory)
        .where(and(eq(userId), eq(pptId))).limit(1);
      if (existing.length > 0) throw new Error('已下载过');
      break;
      
    case 'credits':
      // 检查余额 + 扣减积分
      const balance = await getUserCredits(userId);
      if (balance < requiredCredits) throw new Error('积分不足');
      await consumeCredits({ userId, amount: requiredCredits });
      break;
      
    case 'ad':
      // 验证 downloadToken
      const valid = await validateDownloadToken(downloadToken);
      if (!valid) throw new Error('Token 无效');
      break;
  }
  
  // 4. 记录下载历史
  await db.insert(userDownloadHistory).values({ userId, pptId, method, ... });
  
  // 5. 自增下载计数
  await recordDownload(id);
  
  // 6. 返回文件链接
  return { success: true, data: { fileUrl: ppt.file_url } };
}
```

// src/credits/credits.ts
export async function getUserCredits(userId: string): Promise<number> {
  const record = await db
    .select({ credits: userCredit.currentCredits })
    .from(userCredit)
    .where(eq(userCredit.userId, userId))
    .limit(1);
  return record[0]?.credits ?? 0;
}
```

#### 5.1.3 广告每日限额查询
```typescript
// src/lib/ad-watch-limiter.ts
export async function getUserWatchCount(userId: string): Promise<number> {
  const today = new Date();
  today.setHours(0, 0, 0, 0);
  
  const records = await db
    .select({ count: sql<number>`count(*)` })
    .from(adWatchRecord)
    .where(
      and(
        eq(adWatchRecord.userId, userId),
        eq(adWatchRecord.status, 'completed'),
        gte(adWatchRecord.createdAt, today)
      )
    );
  return Number(records[0]?.count || 0);
}
```

```sql
SELECT COUNT(*) FROM ad_watch_record
WHERE user_id = $1

UPDATE ppt SET download_count = download_count + 1 WHERE id = $1;

### 6.2 索引覆盖分析

| 查询场景 | 涉及字段 | 现有索引 | 覆盖情况 |
|----------|----------|----------|----------|
| 首免校验 | `user_id, ppt_id` | `download_user_ppt_idx` | ✅ 完全覆盖 |
| 积分查询 | `user_id` | `user_credit_user_id_idx` | ✅ 完全覆盖 |
| Token 查询 | `watch_token` | `ad_watch_token_idx` | ✅ 完全覆盖 |

| IP 限额 | `ip_address, status, created_at` | 多个单列索引 | ⚠️ 需复合索引 |

## 八、优缺点分析与改进建议 (Step 8)

### 8.1 优点

| 维度 | 评估 | 说明 |

| **功能完整性** | ⭐⭐⭐⭐⭐ | 四种下载方式完整实现，Token 双阶段验证确保广告真实性 |

| **可配置性** | ⭐⭐⭐⭐⭐ | websiteConfig 集中管理所有开关和参数 |

### 8.2 潜在问题

| 问题 | 严重程度 | 影响 |
|------|----------|------|
| **未登录首免无 IP 频控** | 🔴 高 | 恶意用户可清 Cookie 无限首免 |
| **文件直链无签名** | 🟡 中 | 链接泄露后可被任意访问 |
| **下载 API 无限流** | 🟡 中 | 可能被恶意刷下载 |
| **广告每日限额索引** | 🟢 低 | 统计查询未走复合索引 |
| **downloadToken 未消费标记** | 🟢 低 | Token 理论上可重复使用 |

### 8.3 改进建议

#### 短期 (P0 - 本周)

```markdown
- [ ] **IP 频控首免**: 在 `firstFree` 分支添加 IP hash 校验
      ```typescript
      if (!userId && method === 'firstFree') {
        const ipHash = hashIP(ip);
        const ipDownloads = await db.select().from(userDownloadHistory)
          .where(eq(userDownloadHistory.ipAddress, ipHash));
        if (ipDownloads.length >= 3) throw new Error('IP 下载次数已达上限');
      }
      ```

- [ ] **下载 API 限流**: 添加 rate-limiter-flexible
      ```typescript
      // 每用户每分钟最多 10 次下载请求
      const rateLimiter = new RateLimiterMemory({
        points: 10,
        duration: 60,
      });
      ```
```

#### 中期 (P1 - 本月)

```markdown
- [ ] **签名 URL**: 使用 S3 presigned URL 替代直链
      ```typescript
      const signedUrl = await s3.getSignedUrl(new GetObjectCommand({
        Bucket: bucket,
        Key: ppt.fileKey,
      }), { expiresIn: 3600 }); // 1小时有效
      ```

- [ ] **广告限额复合索引**: 
      ```sql
      CREATE INDEX ad_watch_user_status_date_idx 
        ON ad_watch_record(user_id, status, created_at);
      CREATE INDEX ad_watch_ip_status_date_idx 
        ON ad_watch_record(ip_address, status, created_at);
      ```

- [ ] **Token 消费标记**:
      ```typescript
      // 在 ad_watch_record 表添加 download_token_used 字段
      await db.update(adWatchRecord)
        .set({ downloadTokenUsed: true })
        .where(eq(adWatchRecord.downloadToken, token));
      ```
```

#### 长期 (P2 - 下季度)

```markdown
- [ ] **下载队列**: 高并发场景引入消息队列异步处理
- [ ] **CDN 鉴权**: 集成 Cloudflare 签名 URL 或 Workers 鉴权
- [ ] **下载分析看板**: 按时间/方式/分类统计下载数据
- [ ] **订阅下载**: 支持订阅用户无限下载
```
