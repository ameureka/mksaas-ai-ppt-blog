**文件**: `src/db/schema.ts`

```typescript
export const ppt = pgTable("ppt", {
  id: text("id").primaryKey(),
  title: text("title").notNull(),
  category: text("category"),               // 分类 slug
  status: text("status").default('draft'),  // draft, published, archived
  deletedAt: timestamp("deleted_at"),       // 软删除
  // ... 其他字段
}, (table) => ({
  pptCategoryIdx: index("ppt_category_idx").on(table.category),
  pptStatusIdx: index("ppt_status_idx").on(table.status),
  // 现有索引还包括复合 status+created_at、download/view、embedding HNSW 等
}));
```

| 属性 | 值 |

## 七、潜在问题分析

### 7.1 数据层问题

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| ⚠️ 无软删除过滤 | 中 | API 只过滤 `status='published'`，未过滤 `deleted_at` |
| ⚠️ 无数据库约束 | 低 | category 字段无枚举约束，可能存在脏数据 |
| ⚠️ 数据分布不均 | 中 | 部分分类数据过少，影响用户体验 |

### 7.2 前端层问题

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| ⚠️ 无加载状态 | 低 | 初始 count=0，API 返回前显示"0个模板" |
| ⚠️ 无错误处理 | 低 | API 失败时静默失败，保持 count=0 |
| ⚠️ 无缓存机制 | 中 | 每次访问都请求 API |
| ⚠️ 排序固定 | 低 | 分类顺序固定，非按热度排序 |

### 7.3 配置层问题

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| ⚠️ 配置分散 | 低 | 分类定义在 ppt.ts，元数据在 ppt-category-meta.ts |
| ⚠️ 预览图硬编码 | 低 | 预览图路径硬编码，无动态获取 |

## 八、改进建议

### 8.1 API 层优化

```typescript
// src/app/api/ppts/stats/route.ts
const counts = await db
  .select({
    category: ppt.category,
    count: sql<number>`count(*)::int`,
  })
  .from(ppt)
  .where(and(
    eq(ppt.status, 'published'),
    isNull(ppt.deletedAt)  // 添加软删除过滤
  ))
  .groupBy(ppt.category);
```

### 8.2 前端加载状态

```typescript
const [isLoading, setIsLoading] = useState(true);

useEffect(() => {
  setIsLoading(true);
  fetch('/api/ppts/stats')
    .then(res => res.json())
    .then(json => {
      if (json.success) {
        // 更新状态
      }
    })
    .finally(() => setIsLoading(false));
}, []);

// 渲染时
{isLoading ? (
  <CategorySkeleton />
) : (
  categories.map(...)
)}
```

### 8.3 按热度排序

```typescript
const categories = useMemo(() =>
  PPT_CATEGORIES
    .map(cat => ({ ...cat, count: categoryStats[cat.value]?.count || 0 }))
    .sort((a, b) => b.count - a.count),  // 按数量降序
  [categoryStats]
);
```

### 8.4 添加缓存

```typescript
// API 层添加缓存头
return Response.json(
  { success: true, data: stats },
  {
    headers: {
      'Cache-Control': 'public, s-maxage=300, stale-while-revalidate=600',
    },
  }
);
```

### 8.5 数据库约束

```sql
-- 添加枚举类型
CREATE TYPE ppt_category AS ENUM (
  'business', 'education', 'technology', 'design',
  'marketing', 'hr', 'medical', 'finance',
  'general', 'summary', 'report', 'plan'
```
