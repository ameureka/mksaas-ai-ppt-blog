# PPT 定制服务商业化方案

## 一、商业模式概述

### 核心定位
PPTHub 作为 PPT 模板平台，通过免费模板引流，转化为付费定制服务。

### 收入预估
- 日均线索：10 个
- 转化率：30%
- 平均客单价：300 CNY
- **日收入：900 CNY**
- **月收入：27,000 CNY**

---

## 二、用户转化漏斗

```
免费模板浏览 → 下载/注册 → 定制需求触发 → 咨询表单 → 销售跟进 → 成交
```

### 关键触发点
1. **模板详情页**：用户浏览但未找到完全匹配的模板
2. **搜索无结果**：搜索关键词无匹配时推荐定制
3. **下载后**：下载完成页面推荐定制升级
4. **会员中心**：VIP 用户专属定制入口

---

## 三、定制服务产品线

### 3.1 基础定制（99-199 CNY）
- 现有模板基础上修改配色/字体
- 替换 Logo 和品牌元素
- 调整页面数量（±5页）
- 交付时间：1-2 工作日

### 3.2 标准定制（299-599 CNY）
- 基于需求重新设计版式
- 包含 15-25 页
- 提供 2 次修改
- 交付时间：3-5 工作日

### 3.3 高端定制（999-2999 CNY）
- 完全原创设计
- 包含动画效果
- 配套 Word/Excel 模板
- 无限次修改直到满意
- 交付时间：5-10 工作日

### 3.4 企业年度服务（9999+ CNY）
- 年度 PPT 设计服务
- 专属设计师对接
- 品牌 VI 系统整合
- 优先响应

### 4.2 数据库表设计

```sql
-- 定制需求表
CREATE TABLE customization_request (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES "user"(id),
  
  -- 联系信息
  contact_name VARCHAR(100) NOT NULL,
  contact_phone VARCHAR(20),
  contact_wechat VARCHAR(50),
  contact_email VARCHAR(255),
  
  -- 需求信息
  service_type VARCHAR(20) NOT NULL, -- basic/standard/premium/enterprise
  description TEXT NOT NULL,
  page_count INTEGER,
  deadline DATE,
  budget_range VARCHAR(50),
  reference_ppt_id UUID REFERENCES ppt(id),
  
  -- 状态跟踪
  status VARCHAR(20) DEFAULT 'pending', -- pending/contacted/quoted/paid/completed/cancelled
  assigned_to VARCHAR(100),
  quoted_price DECIMAL(10,2),
  final_price DECIMAL(10,2),
  
  -- 来源追踪
  source VARCHAR(50), -- detail/search/download/sidebar/ad
  source_keyword VARCHAR(255),
  source_ppt_id UUID,
  utm_source VARCHAR(100),
  utm_medium VARCHAR(100),
  utm_campaign VARCHAR(100),
  
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  contacted_at TIMESTAMP,
  completed_at TIMESTAMP
);

-- 索引
CREATE INDEX idx_customization_status ON customization_request(status);
CREATE INDEX idx_customization_created ON customization_request(created_at DESC);
CREATE INDEX idx_customization_user ON customization_request(user_id);
```

### 4.4 API 端点

```typescript
// src/app/api/customization/route.ts
import { db } from '@/db'
import { customizationRequest } from '@/db/schema'
import { NextResponse } from 'next/server'
import { z } from 'zod'

const requestSchema = z.object({
  contactName: z.string().min(1),
  contactPhone: z.string().optional(),
  contactWechat: z.string().optional(),
  contactEmail: z.string().email().optional(),
  serviceType: z.enum(['basic', 'standard', 'premium', 'enterprise']),
  description: z.string().min(10),
  pageCount: z.number().optional(),
  deadline: z.string().optional(),
  budgetRange: z.string().optional(),
  referencePptId: z.string().uuid().optional(),
  source: z.string().optional(),
  sourceKeyword: z.string().optional(),
})

export async function POST(req: Request) {
  try {
    const body = await req.json()
    const data = requestSchema.parse(body)
    
    const [result] = await db.insert(customizationRequest).values({
      ...data,
      deadline: data.deadline ? new Date(data.deadline) : null,
    }).returning({ id: customizationRequest.id })
    
    // TODO: 发送通知邮件/企业微信
    
    return NextResponse.json({ success: true, id: result.id })
  } catch (error) {
    return NextResponse.json({ error: 'Invalid request' }, { status: 400 })
  }
}
```

### 6.2 来源分析 SQL
```sql
-- 各渠道转化效果
SELECT 
  source,
  COUNT(*) as total_requests,
  COUNT(CASE WHEN status = 'completed' THEN 1 END) as completed,
  ROUND(AVG(final_price), 2) as avg_price,
  SUM(final_price) as total_revenue
FROM customization_request
WHERE created_at > NOW() - INTERVAL '30 days'
GROUP BY source
ORDER BY total_revenue DESC;
```
