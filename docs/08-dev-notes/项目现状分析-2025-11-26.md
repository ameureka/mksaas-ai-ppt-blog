## 🏗️ 项目架构概览

### 核心技术栈
```
Frontend:
├─ Framework: Next.js 15 (App Router)
├─ UI Library: React 19
├─ Styling: TailwindCSS 4.0 + Radix UI
├─ State: Zustand + React Query (TanStack Query)
├─ i18n: next-intl (英文、中文)
└─ TypeScript: 5.8.3

Backend:
├─ Runtime: Node.js 18+
├─ Database: PostgreSQL + Drizzle ORM
├─ Auth: Better Auth (支持 OAuth + Email)
├─ Payment: Stripe API
├─ Email: Resend
└─ Storage: S3 Compatible

Content:
├─ Blog/Docs: Fumadocs + MDX
├─ Code Highlighting: Shiki
└─ Search: Orama Search

AI Integrations:
├─ Image Gen: Replicate, OpenAI, Fireworks, FAL
├─ Chat: OpenAI, Gemini, DeepSeek, OpenRouter
├─ Web Scraping: Firecrawl
└─ AI SDK: Vercel AI SDK 5.0
```
