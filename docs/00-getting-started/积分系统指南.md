## 📊 积分系统概览

### 什么是积分系统？

积分系统是一种计费模式，用户通过购买或获赠积分来使用应用的付费功能。

**使用场景**:
- AI 功能调用（每次消耗 X 积分）
- 图片生成（每张消耗 X 积分）
- API 调用（每次消耗 X 积分）
- 高级功能使用

## 🚀 如何启用积分系统

### Step 1: 修改配置文件

编辑 `src/config/website.tsx`：

```typescript
credits: {
  enableCredits: true,  // 改为 true
  enablePackagesForFreePlan: false,  // 是否允许免费用户购买积分包
  registerGiftCredits: {
    enable: true,        // 注册赠送积分
    amount: 50,          // 赠送数量
    expireDays: 30,      // 有效期（天）
  },
  packages: {
    // 积分包配置...
  },
}
```

### Step 2: 重启开发服务器

```bash
# 停止当前服务器（Ctrl+C）
# 重新启动
pnpm dev
```

### Step 3: 访问积分页面

```
http://localhost:3005/settings/credits
```

## 📂 积分系统文件结构

### 数据库 Schema

```typescript
// src/db/schema.ts

// 用户积分表
export const userCredit = pgTable('user_credit', {
  id: text('id').primaryKey(),
  userId: text('userId').notNull(),
  balance: integer('balance').default(0),  // 当前余额
  totalEarned: integer('totalEarned').default(0),
  totalSpent: integer('totalSpent').default(0),
  createdAt: timestamp('createdAt').defaultNow(),
  updatedAt: timestamp('updatedAt').defaultNow(),
});

// 积分交易记录表
export const creditTransaction = pgTable('credit_transaction', {
  id: text('id').primaryKey(),
  userId: text('userId').notNull(),
  amount: integer('amount').notNull(),     // 积分数量（正数=获得，负数=消耗）
  type: text('type').notNull(),            // 交易类型
  description: text('description'),
  expiresAt: timestamp('expiresAt'),       // 过期时间
  createdAt: timestamp('createdAt').defaultNow(),
});
```

## 💡 使用示例

### 示例 1: 在功能中消耗积分

```typescript
// src/app/api/generate-image/route.ts
import { consumeCredits } from '@/credits/credits';
import { getSession } from '@/lib/server';

export async function POST(request: Request) {
  const session = await getSession();
  if (!session) {
    return Response.json({ error: 'Unauthorized' }, { status: 401 });
  }

  // 检查积分是否足够
  const credits = await getUserCredits(session.user.id);
  const requiredCredits = 10;

  if (credits.balance < requiredCredits) {
    return Response.json(
      { error: '积分不足' },
      { status: 400 }
    );
  }

  // 执行功能...
  const result = await generateImage(/* ... */);

  // 消耗积分
  await consumeCredits({
    userId: session.user.id,
    amount: requiredCredits,
    type: 'image_generation',
    description: '生成图片',
  });

  return Response.json({ result });
}
```

## 📊 管理员功能

### 手动给用户添加积分

创建脚本 `scripts/add-credits.ts`：

```typescript
import { addCredits } from '@/credits/credits';

async function giveCredits(email: string, amount: number) {
  // 查找用户
  const user = await db.query.user.findFirst({
    where: eq(user.email, email),
  });

  if (!user) {
    console.error('用户不存在');
    return;
  }

  // 添加积分
  await addCredits({
    userId: user.id,
    amount: amount,
    type: 'admin_gift',
    description: '管理员赠送',
    expireDays: 30,
  });

  console.log(`✅ 已给 ${email} 添加 ${amount} 积分`);
}

// 使用
giveCredits('user@example.com', 100);
```

运行：
```bash
pnpm tsx scripts/add-credits.ts
```

## 🔍 调试和监控

### 查看用户积分

```sql
-- 查看所有用户的积分
SELECT 
  u.email,
  uc.balance,
  uc.totalEarned,
  uc.totalSpent
FROM "user" u
LEFT JOIN user_credit uc ON u.id = uc.userId;
```

### 查看积分交易记录

```sql
-- 查看最近的积分交易
SELECT 
  u.email,
  ct.amount,
  ct.type,
  ct.description,
  ct.createdAt
FROM credit_transaction ct
JOIN "user" u ON ct.userId = u.id
ORDER BY ct.createdAt DESC
LIMIT 20;
```

## 💡 常见问题

### Q1: 为什么访问 /settings/credits 被重定向？

**A**: 积分系统被禁用了。需要在 `src/config/website.tsx` 中设置：
```typescript
credits: {
  enableCredits: true,
}
```

### Q2: 如何修改积分包价格？

**A**: 编辑 `src/config/website.tsx` 中的 `credits.packages` 配置。

### Q3: 积分会过期吗？

**A**: 是的，每个积分都有 `expiresAt` 字段。默认配置是 30 天。

### Q4: 如何查看某个用户的积分？

**A**: 使用 Drizzle Studio 或 SQL 查询：
```bash
pnpm db:studio
```

### Q5: 如何测试积分功能？

**A**: 
1. 启用积分系统
2. 使用脚本给自己添加测试积分
3. 在功能中集成积分消耗逻辑
4. 测试购买流程（需要 Stripe 测试模式）
