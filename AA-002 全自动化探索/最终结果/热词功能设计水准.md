# 热词功能的设计水准

热词功能达到了**生产级智能推荐系统**的水准，具体包括：

## 1. 双层数据源架构
- **自动热词表** (`hot_keywords`)：基于数据分析自动生成
- **置顶关键词表** (`pinned_keywords`)：运营人工配置，优先级更高
- 合并策略：置顶词优先，自动词补充，最多展示8个

## 2. 智能算法评分系统
计算公式：`最终得分 = 搜索权重(60%) + 下载权重(40%)`

- **搜索维度**：统计最近7天的 `search_log` 表，反映用户真实需求
- **下载维度**：从 PPT 的 `tags` 字段提取，统计下载量，反映内容质量
- **归一化处理**：对两个维度分别归一化后加权合并，避免数值量级差异

## 3. 自动化更新机制
- **定时任务**：`/api/cron/update-hot-keywords` 端点，配合 Vercel Cron
- **安全验证**：使用 `CRON_SECRET` 环境变量验证请求来源
- **手动触发**：支持 `pnpm update-hot-keywords` 命令手动更新

## 4. 运营管理能力
- **管理端点**：`/api/admin/pinned-keywords` 提供 CRUD 接口
- **权限控制**：仅 `admin` 和 `super_admin` 角色可操作
- **排序管理**：支持 rank 字段控制展示顺序
- **去重机制**：置顶词不会与自动词重复

## 5. 容错与降级
- **默认兜底**：数据库查询失败时返回硬编码的8个默认热词
- **优雅降级**：前端 API 调用失败时保持默认值，不影响页面展示

## 6. 数据库优化
- **索引设计**：rank 字段和 keyword 字段都有唯一索引，查询高效
- **时间戳**：记录 `created_at` 和 `updated_at`，便于追踪更新历史

## 技术实现文件清单

### 数据库层
- `src/db/schema.ts` - 表定义（hot_keywords, pinned_keywords）
- `scripts/create-hot-keywords-table.sql` - 建表脚本

### 业务逻辑层
- `src/actions/hot-keywords.ts` - 获取热词逻辑（合并置顶+自动）
- `scripts/update-hot-keywords.ts` - 热词更新算法

### API层
- `src/app/api/hot-keywords/route.ts` - 前端获取热词接口
- `src/app/api/cron/update-hot-keywords/route.ts` - 定时更新端点
- `src/app/api/admin/pinned-keywords/route.ts` - 运营管理接口

### 前端展示
- `src/app/[locale]/(marketing)/ppt/page.tsx` - 热词展示与点击
