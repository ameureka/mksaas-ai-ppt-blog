## Kiro CLI 核心特性总览

### 1. 基础命令 (斜杠命令)

| 命令 | 功能 |
|------|------|
| /quit | 退出应用 |
| /clear | 清除对话历史 |
| /save / /load | 保存/加载对话 |
| /compact | 压缩对话以释放上下文空间 |
| /context | 管理上下文文件，查看上下文窗口使用情况 |
| /editor | 打开编辑器编写提示词 |
| /tools | 查看工具和权限 |
| /mcp | 查看已加载的 MCP 服务器 |
| /model | 切换当前会话的模型 |
| /agent | 管理 agents |

### 2. 内置工具

- execute_bash - 执行 shell 命令
- fs_read - 读取文件、目录、图片
- fs_write - 创建和编辑文件
- use_aws - 调用 AWS CLI API
- web_search / web_fetch - 网络搜索和内容获取
- introspect - 查询 Kiro CLI 自身能力

### 3. 实验性功能 (/experiment 开启)

| 功能 | 说明 |
|------|------|
| Checkpointing | 文件变更快照，可回滚 |
| Tangent Mode | 对话分支，探索旁支话题后可返回主线 |
| Knowledge | 跨会话的持久化知识库 |
| Thinking | 复杂推理的思考过程展示 |
| TODO Lists | 任务列表管理 (/todos) |
| Delegate | 后台异步任务委派 |

### 4. Agent 配置

Agent 文件位置：
- 本地 (项目级): .kiro/agents/
- 全局 (用户级): ~/.kiro/agents/

可配置：
- 工具权限 (allowedTools)
- 工具设置 (toolsSettings) - 如允许的路径、命令
- Hooks (钩子) - 在特定时机执行自定义命令

### 5. 实用技巧

bash
# 查看/修改设置
kiro-cli settings chat.enableTangentMode true

# 快捷键
Ctrl+T  # 切换 Tangent Mode
Ctrl+S  # 模糊搜索命令


### 6. 对你项目有用的配置建议

针对你的 PPTHub 项目，可以考虑：

json
// .kiro/agents/ppthub-dev.json
{
  "description": "PPTHub 开发助手",
  "allowedTools": ["fs_read", "fs_write", "execute_bash"],
  "toolsSettings": {
    "fs_write": {
      "allowedPaths": ["./src/**", "./content/**"]
    },
    "execute_bash": {
      "allowedCommands": ["pnpm dev", "pnpm lint", "pnpm build"],
      "autoAllowReadonly": true
    }
  }
}

## 关键能力组合

### 1. Delegate (后台任务委派) - 最接近你需求的功能

/experiment  # 开启 Delegate 功能


特点：
- 启动后台异步任务，主对话可继续
- 任务完成后自动通知
- 支持指定不同 agent 执行不同任务
- 任务结果自动加入对话上下文

但限制是：每个 agent 同时只能运行一个任务，且需要 CLI 保持运行状态。

### 2. TODO Lists - 任务追踪和恢复

/experiment  # 开启 TODO List
/todos resume  # 恢复之前的任务列表


特点：
- 任务列表持久化存储在 .kiro/cli-todo-lists/
- 可以中断后恢复继续执行
- 自动追踪完成状态

### 3. Hooks - 自动化触发

可以配置 agent 在特定时机自动执行命令：
- agentSpawn - agent 启动时
- preToolUse / postToolUse - 工具执行前后
- stop - 每轮对话结束时

## 实现长时间无人值守的方案

方案 A：TODO List + 自动恢复脚本

bash
# 创建一个 wrapper 脚本
#!/bin/bash
while true; do
  kiro-cli chat --agent ppthub-worker << 'EOF'
/todos resume
继续执行未完成的任务
EOF
  sleep 60  # 如果退出了，等待后重试
done


方案 B：配置 Agent + Hooks 实现自动化流水线

json
// .kiro/agents/auto-worker.json
{
  "description": "自动化工作 agent",
  "allowedTools": ["fs_read", "fs_write", "execute_bash", "todo_list"],
  "toolsSettings": {
    "execute_bash": {
      "autoAllowReadonly": true,
      "allowedCommands": ["pnpm.*", "git status", "git add.*", "git commit.*"]
    },
    "fs_write": {
      "allowedPaths": ["./src/**", "./content/**"]
    }
  },
  "hooks": [
    {
      "event": "stop",
      "command": ["bash", "-c", "echo 'Task completed at $(date)' >> .kiro/task.log"]
    }
  ]

+    390: export async function sqlSearch(
+    391:   query: string,

+    393: ): Promise<PPT[]> {
+    394:   const db = await getDb();
+    395:   const keyword = `%${query.trim()}%`;
+    396:
+    397:   const results = await db
+    398:     .select()
+    399:     .from(pptTable)
+    400:     .where(and(
+    401:       isNull(pptTable.deletedAt),
+    402:       or(
+    403:         ilike(pptTable.title, keyword),
+    404:         ilike(pptTable.description, keyword),
+    405:         ilike(pptTable.author, keyword),
+    406:         sql`array_to_string(${pptTable.tags}, ',') ILIKE ${keyword}`
+    407:       )
+    408:     ))

+    415: /**
+    416:  * 混合搜索 (向量优先，SQL 降级)
+    417:  */
+    418: export async function hybridSearch(
+    419:   query: string,
+    420:   limit: number = 20
+    421: ): Promise<{ results: PPT[]; searchType: 'vector' | 'sql' | 'hybrid' }> {
+    422:   // 1. 尝试向量搜索
+    423:   const vectorResults = await vectorSearch(query, limit);
+    424:
+    425:   // 2. 向量搜索成功且结果充足
+    426:   if (vectorResults.length >= 5) {

+    428:       results: vectorResults.map(r => toPPTDto(r)),
+    429:       searchType: 'vector',
+    430:     };
+    431:   }
+    432:
+    433:   // 3. 向量搜索结果不足，SQL 补充
+    434:   if (vectorResults.length > 0) {
+    435:     const existingIds = new Set(vectorResults.map(r => r.id));
+    436:     const sqlResults = await sqlSearch(query, limit - vectorResults.length);
+    437:     const additionalResults = sqlResults.filter(r => !existingIds.has(r.id));
+    438:

+    446:   }

+    452:     searchType: 'sql',

+    454: }
