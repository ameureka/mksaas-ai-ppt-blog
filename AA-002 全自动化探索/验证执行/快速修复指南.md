# 🚀 PPT 搜索系统快速修复指南

## 当前状态
- ✅ 代码已完成并通过编译

- ❌ 向量生成失败（API 认证问题）

## 🔧 3分钟快速修复

### 1️⃣ 获取免费 API Key（1分钟）

选择以下任一方案：

#### 方案 A: SiliconFlow（推荐，免费额度高）
1. 访问: https://siliconflow.cn
2. 注册/登录
3. 进入控制台 → API Keys
4. 创建新的 API Key
5. 复制 key

#### 方案 B: 修复 OpenRouter
1. 访问: https://openrouter.ai/keys
2. 登录后创建新 key
3. 确保 key 格式: `sk-or-v1-...`

### 2️⃣ 配置环境变量（30秒）

编辑 `.env.local`:
```bash
# 添加以下行（选择一个）
SILICONFLOW_API_KEY=sf_xxxxxxxxxxxx  # 方案A
# 或
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxx  # 方案B
```

### 3️⃣ 数据库设置（1分钟）

1. 打开 Neon 控制台: https://console.neon.tech
2. 选择你的数据库
3. 点击 "SQL Editor"
4. 粘贴并运行:

```sql
-- 一键执行全部设置
CREATE EXTENSION IF NOT EXISTS vector;

ALTER TABLE ppt 
ADD COLUMN IF NOT EXISTS embedding vector(1024),
ADD COLUMN IF NOT EXISTS embedding_model VARCHAR(100);

CREATE INDEX IF NOT EXISTS ppt_embedding_idx 
ON ppt USING hnsw (embedding vector_cosine_ops);
```

### 4️⃣ 运行验证（30秒）

```bash
# 重启服务器加载新配置
pkill -f "next dev" && pnpm dev &

# 等待5秒后测试
sleep 5 && pnpm exec tsx scripts/test-embedding-api.ts
```

如果看到 "✅ 成功生成向量"，说明配置成功！

## ❓ 常见问题

### Q: API key 还是返回 401？
A: 检查 key 格式:
- SiliconFlow: 应该以 `sf_` 开头
- OpenRouter: 应该以 `sk-or-v1-` 开头

### Q: 数据库命令执行失败？
A: 可能原因:
- pgvector 扩展需要超级用户权限
- 联系 Neon 支持启用 pgvector

### Q: 生成向量很慢？
A: 正常现象，每个请求间隔 200ms 避免限流
