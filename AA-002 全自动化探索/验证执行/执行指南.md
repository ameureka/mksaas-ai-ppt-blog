### 步骤 1：查看当前状态（可选）
在 Neon 控制台执行：
```sql
-- 文件：01-数据清理/check-current-status.sql
SELECT 
  COUNT(*) as total_ppts,
  COUNT(embedding) as with_embedding,
  COUNT(DISTINCT embedding_model) as model_types,
  STRING_AGG(DISTINCT embedding_model, ', ') as models_used
FROM ppt;
```

### 步骤 2：清理旧数据 ⚠️ 重要
在 Neon 控制台执行：
```sql
-- 文件：01-数据清理/clean-old-embeddings.sql
UPDATE ppt 
SET 
  embedding = NULL, 
  embedding_model = NULL,
  updated_at = NOW()
WHERE embedding IS NOT NULL;

-- 验证清理（应返回0）
SELECT COUNT(*) as remaining_embeddings 
FROM ppt 
WHERE embedding IS NOT NULL;
```
