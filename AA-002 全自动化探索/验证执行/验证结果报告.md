## ❗ 发现的问题

### 1. API Key 认证问题
- OPENROUTER_API_KEY 返回 401 错误
- 需要验证 API key 是否有效
- 建议添加 SILICONFLOW_API_KEY（免费额度高）

### 2. 数据库权限问题
- Neon 数据库无法通过脚本添加字段
- 需要在 Neon 控制台手动执行 SQL

### 3. API 端点问题
- 多个搜索 API 返回非 JSON 格式
- 可能是路由配置或中间件问题

## 🚀 立即行动清单

### 步骤 1: 数据库设置（在 Neon 控制台执行）

```sql
-- 在 Neon 控制台执行以下 SQL
CREATE EXTENSION IF NOT EXISTS vector;

ALTER TABLE ppt 
ADD COLUMN IF NOT EXISTS embedding vector(1024),
ADD COLUMN IF NOT EXISTS embedding_model VARCHAR(100);

CREATE INDEX IF NOT EXISTS ppt_embedding_idx 
ON ppt USING hnsw (embedding vector_cosine_ops);

CREATE TABLE IF NOT EXISTS search_log (
  id SERIAL PRIMARY KEY,
  keyword VARCHAR(255) NOT NULL,
  result_count INTEGER DEFAULT 0,
  clicked_id VARCHAR(255),
  user_id VARCHAR(255),  
  session_id VARCHAR(255),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 步骤 2: 配置 API Keys

在 `.env.local` 添加:
```bash
# 推荐使用硅基流动（免费额度高）
SILICONFLOW_API_KEY=your_key_here

# 或修正 OpenRouter key
OPENROUTER_API_KEY=sk-or-v1-your_valid_key_here
```

获取 API Key:
- SiliconFlow: https://siliconflow.cn/account/ak
- OpenRouter: https://openrouter.ai/keys

### 步骤 3: 生成向量和热词

```bash
# 1. 确认数据库设置完成后
pnpm generate-embeddings

# 2. 更新热门关键词
pnpm update-hot-keywords

# 3. 重启服务器
pnpm dev
```

### 步骤 4: 前端集成

在 `/src/app/[locale]/(marketing)/ppt/page.tsx` 中使用新的 SearchBox 组件替换现有搜索框。
